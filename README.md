# Brain Train Hub - Ultimate

A comprehensive hub for brain training games and cognitive exercises.

## Setup for GitHub Pages

This repository is configured to work with GitHub Pages. The main entry point is `index.html` (which should be a copy of `brain-train-hub.html`).

### To enable GitHub Pages:

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Choose the `main` branch and `/ (root)` folder
5. Click "Save"

Your site will be available at: `https://dolev765.github.io/Brain-Train-Hub-Ultimate-/`

### Note:

If `index.html` doesn't exist yet, you need to copy `brain-train-hub.html` to `index.html`:

```powershell
Copy-Item "brain-train-hub.html" "index.html"
```

Or on Linux/Mac:
```bash
cp brain-train-hub.html index.html
```

## Games Included

- **Syllogimous**: Logic and syllogism training
- **3D MOT**: Multiple Object Tracking in 3D space
- **Trial & Error Reading**: Text manipulation and pattern recognition
- **Peripheral Trainer**: Peripheral vision training
- **Brain Train Epson**: Mental arithmetic training
- **Bridge Analogy**: Analogical reasoning with AI

## Features

- Comprehensive settings for each game
- Round-based training system
- Reinforcement system (optional)
- Cross-game progress tracking
